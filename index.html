Drop Into Your Own Website

nesticle-cursor/

The cursor is packaged as a standalone, zero-dependency module ready to be dropped into any project:

<link rel="stylesheet" href="nesticle-cursor/nesticle-cursor.css">
<script src="nesticle-cursor/nesticle-cursor.js"></script>
<script>
  const cursor = new NesticleCursor({
    mode: 'follower',    // 'follower' | 'native-swap' | 'static'
    scale: 1,            // 1x = 42x62px
    clickEffect: true    // Blood splatter particles on click
  });
</script>
